## 1.0.0 (2026-09-07)

### ⚠ BREAKING CHANGES

* the toolchain moves from Create React App to Vite and the
package now requires Node 26. `npm start` serves on port 3000 as before, but
the build output moves from `build/` to `dist-web/`.

react-scripts 5 was the blocker for everything else here: it is unmaintained,
pins its own webpack/babel/jest stack, and does not run on Node 26. Replacing
it with Vite 8 is what let every other dependency go to its current major.

- Node 26 (`engines`, and every workflow's `setup-node`)
- React 17 -> 19: `ReactDOM.render` -> `createRoot`, the automatic JSX runtime
  (so the unused `React` default imports go), and the `react-app-polyfill`
  IE11 shims dropped
- React 18+ batching: `MineSweeper.startGame` measured the board on the line
  after `setState`, which no longer sees the new state, so it sized every
  sprite from the *previous* level's grid. It now measures from the setState
  callback. `DrawSprite` had the same shape of bug in a mount effect that
  wrote to a local recomputed on every render; the offset is derived instead.
- enzyme -> Testing Library, jest -> Vitest. enzyme has no React 17+ adapter,
  so this was forced; the shallow-render snapshots are regenerated as DOM.
- web-vitals 2 -> 6: `getX` -> `onX`, and FID is gone in favour of INP
- node-sass -> dart-sass, and `@import` -> `@use`. The Press Start 2P webfont
  moves from a CSS `@import` to a preconnected `<link>`.
- ESLint 9 flat config, Prettier and `tsc --noEmit` added as CI gates; the
  `any`s those turned up on event handlers and timer handles are now typed
- TypeScript 4.5 -> 5.9. Not 7.0: typescript-eslint 8 peers on `<6.1.0`.

CI and release workflows are lifted from the scumm repo, with the release
trigger re-enabled so merging a pull request to `master` cuts a release and
publishes the site. Vite's `base` is set to `/mine-sweeper/` because Pages
serves a project site from a subpath.

Version set to 1.0.0. `.github/CODEOWNERS` makes @adrianeyre the owner of
every path.
